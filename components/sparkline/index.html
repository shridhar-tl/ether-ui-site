Sparkline

Mini inline trend charts for KPI cards, table cells and running text. Line, area, bar, win/loss, discrete, bullet and pie types with markers, reference lines, bands, trend colors, tooltips and full keyboard and screen reader support. No chart library required.

Basic Usage

Inline Trends

Tiny charts that fit inside text, cards and table cells. Hover or focus to inspect values.

Line
Area
Bar

Revenue grew 12.5% this quarter while sign-ups kept climbing .

import { Sparkline } from 'fluxo-ui';

<Sparkline data={[42, 48, 45, 52, 58, 55, 63, 61, 70, 74, 72, 81]} />
<Sparkline type="area" color="success" data={signups} />
<Sparkline type="bar" data={profit} />

Tooltips, Events & Keyboard

Tooltips, Events & Keyboard

Focus the chart and use the arrow keys, Home and End to move between points. Values are announced to screen readers.

Revenue · Dec$81.0k
Click a point to pin it.
<Sparkline
    type="area"
    data={[{ value: 42, label: 'Jan' }, { value: 48, label: 'Feb' }]}
    formatValue={(v) => `$${v}k`}
    renderTooltip={(point) => <strong>{point.label}: {point.value}</strong>}
    onPointHover={setHovered}
    onPointClick={setPinned}
    valueLabel="Revenue"
/>
