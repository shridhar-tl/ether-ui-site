Alert

Contextual messages for feedback, warnings and announcements. Five types, six variants, actions, expandable details, dismiss and auto-close with progress, banners, custom colors and accessible live-region roles.

Basic Usage

Alert Types

Each type has its own icon, color and an appropriate ARIA role.
