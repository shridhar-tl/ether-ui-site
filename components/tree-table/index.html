Tree Table

A virtualized hierarchical data grid built for millions of rows. Lazy-load children page by page, append root rows as you scroll, select with checkboxes that cascade, sort and filter within the hierarchy, roll up totals, edit inline, pin and resize columns and move rows with the mouse or keyboard. Every interaction follows the WAI-ARIA treegrid pattern.

Basic Usage

Nested Data

Pass nested rows with a children array. Folder sizes roll up from their files with aggregate: 'sum'. Use the arrow keys to move, Right/Left to expand and collapse.
