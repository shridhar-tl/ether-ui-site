Overlay Panel

A floating panel anchored to an element, for details, hover cards and small forms. Control it with isOpen, target and onClose.

Click to open

Click to open

Anchored to the button. Closes with the close button, Escape or a click outside.

const [isOpen, setIsOpen] = useState(false);
const targetRef = useRef<HTMLSpanElement>(null);

<span ref={targetRef}>
  <Button onClick={() => setIsOpen((value) => !value)}>Show details</Button>
</span>
<OverlayPanel
  isOpen={isOpen}
  target={targetRef.current}
  onClose={() => setIsOpen(false)}
  title="Release 4.2"
>
  <p>Planned for 20 Nov. 12 of 15 issues are done.</p>
</OverlayPanel>

Hover details

Hover details

Opens on hover or focus without moving focus. The pointer can move into the panel to use its links.

const open = (e: React.MouseEvent<HTMLElement>, member: Member) => {
  window.clearTimeout(hideTimer.current);
  setActive({ target: e.currentTarget, member });
};
const scheduleClose = () => {
  hideTimer.current = window.setTimeout(() => setActive(null), 200);
};

<OverlayPanel
  isOpen={!!active}
  target={active?.target ?? null}
  onClose={() => setActive(null)}
  title={active?.member.name}
  autoFocus={false}
  onMouseEnter={() => window.clearTimeout(hideTimer.current)}
  onMouseLeave={scheduleClose}
>
  {active && <MemberTasks member={active.member} />}
</OverlayPanel>

Footer actions

Footer actions

Use the footer for actions and placement to align the panel with the target.

<OverlayPanel
  isOpen={isOpen}
  target={targetRef.current}
  onClose={() => setIsOpen(false)}
  title="Columns"
  width={240}
  placement="bottomLeft"
  footer={<Button size="sm" onClick={() => setIsOpen(false)}>Apply</Button>}
>
  <Checkbox label="Assignee" checked={assignee} onChange={(e) => setAssignee(e.value)} />
  <Checkbox label="Due date" checked={dueDate} onChange={(e) => setDueDate(e.value)} />
</OverlayPanel>

Features

Anchored Positioning

8 placement options with automatic flipping when space is limited, kept in place while scrolling

Any Content

Render rich content with an optional title and footer. The body scrolls when it is tall

Hover or Click

Use it for click-triggered panels and hover cards. Pointer events reach the panel content

Dismissal

Closes on Escape, the close button or a click outside the panel and target

Mobile Sheet

Shows as a bottom sheet with a backdrop on small screens

Accessibility

Dialog role with an accessible name, focus moves in and is restored on close, reduced motion respected
