Badge

Counters, dots and status indicators that attach to any element or sit inline. Overflow caps, four placements, circular overlap, offsets, pulse and change animations, icons and accessible labels.

Basic Usage

Anchored Badges

Wrap any element to attach a count, dot or icon to its corner.

55 unread notifications99+More than 99 messagesUpdates availableACOnline
import { Badge } from 'fluxo-ui';

<Badge count={5} ariaLabel="5 unread notifications">
    <Button leftIcon={AnnouncementIcon} layout="outlined" ariaLabel="Notifications" />
</Badge>

<Badge dot color="success" overlap="circular" ariaLabel="Online">
    <Avatar name="Ava Chen" />
</Badge>

Placement, Overlap & Offset
