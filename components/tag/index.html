Tag

Compact labels for categorising, filtering and annotating content. Seven variants, semantic and custom colors, icons, avatars, counts, removable and clickable tags, and groups that collapse overflow.

Basic Usage

Status Tags

Use the color prop to give a tag a semantic meaning.

DraftIn reviewPublishedExpiringBlockedBetaArchived
import { Tag } from 'fluxo-ui';

<Tag>Draft</Tag>
<Tag color="primary">In review</Tag>
<Tag color="success">Published</Tag>
<Tag color="warning">Expiring</Tag>
<Tag color="danger">Blocked</Tag>
<Tag color="info">Beta</Tag>

{tags.map((tag) => (
    <Tag
        key={tag}
        color="primary"
        closable
        closeLabel={`Remove ${tag}`}
        onClose={() => setTags((prev) => prev.filter((t) => t !== tag))}
    >
        {tag}
    </Tag>
))}
