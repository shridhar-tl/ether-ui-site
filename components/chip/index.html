Chip

Interactive chips for filtering, choosing, entering and acting. Single and multiple selection groups with keyboard navigation, selection limits, removable input chips, action and link chips, avatars, icons and four variants.

Basic Usage

Filter Chips

Toggle chips to refine a selection. Use arrow keys to move between chips.

import { ChipGroup } from 'fluxo-ui';

<ChipGroup
    multiple
    defaultValue={['italian', 'thai']}
    options={[
        { value: 'italian', label: 'Italian' },
        { value: 'japanese', label: 'Japanese' },
        { value: 'thai', label: 'Thai' },
    ]}
    ariaLabel="Cuisine"
/>
