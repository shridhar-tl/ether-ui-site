Date Picker

Single date selection with typed input, a keyboard-friendly calendar, presets, min and max limits, disabled days, highlights, custom day rendering, month and year modes, locales, and a bottom sheet on small screens.

Basic Usage

Single Date

Open with a click, Alt+Arrow Down, or type a date directly. Navigate the calendar with arrows, Page Up/Down and Home/End.

No date selected
import { DatePicker } from 'fluxo-ui';

const [date, setDate] = useState<Date | null>(null);

<DatePicker value={date} onChange={setDate} placeholder="Select a date" clearable />

Formats, Locales & Week Start

Formats, Locales & Week Start

Display formats use date-fns patterns. Month and weekday names come from the browser's Intl support for any locale.

<DatePicker format="MMM d, yyyy" />
<DatePicker locale="de-DE" firstDayOfWeek={1} showWeekNumbers />

Date Constraints

Date Constraints

Disabled dates are skipped by keyboard navigation and rejected when typed.

<DatePicker minDate={new Date()} maxDate={addMonths(new Date(), 3)} />
<DatePicker disabledDaysOfWeek={[0, 6]} />
<DatePicker disabledDates={[holiday1, holiday2]} />
<DatePicker disabledDates={(date) => date.getDate() % 2 === 1} />

Presets & Footer Actions

Presets & Footer Actions

Quick picks appear beside the calendar and collapse above it on small screens.

<DatePicker
    presets={[
        { label: 'Today', value: () => new Date() },
        { label: 'Tomorrow', value: () => addDays(new Date(), 1) },
        { label: 'Next Monday', value: () => nextMonday(new Date()) },
    ]}
    showTodayButton
    clearable
/>

<DatePicker closeOnSelect={false} showTodayButton todayLabel="Jump to today" />

Custom Parsing, Events & Styling Hooks

Custom Parsing, Events & Styling Hooks

Accept natural input with parseDate, control the popover with open and onOpenChange, listen to focus events, and style days or the popover with your own classes.

Type today, tomorrow, +3d, -1w, +2m or an ISO date, then press Enter.
Full-screen sheet on small screensOffOn
Natural value: none
Interact with the controlled picker to see events.
const parseNaturalDate = (text: string) => {
    if (text === 'today') return startOfDay(new Date());
    if (text === 'tomorrow') return addDays(startOfDay(new Date()), 1);
    const relative = text.match(/^([+-])(\d+)d$/);
    if (relative) return addDays(startOfDay(new Date()), Number(relative[2]) * (relative[1] === '-' ? -1 : 1));
    const iso = parseISO(text);
    return isValid(iso) ? iso : null;
};

<DatePicker parseDate={parseNaturalDate} ariaDescribedBy="natural-hint" />

<DatePicker
    open={open}
    onOpenChange={setOpen}
    onFocus={() => log('focus')}
    onBlur={() => log('blur')}
    dayClassName={(date) => (isWeekend(date) ? 'italic' : undefined)}
    popoverClassName="shadow-2xl"
    responsive={responsive}
/>

Form Integration

Form Integration

The name prop submits an ISO date through a hidden input, so the picker works with native forms.

<form onSubmit={handleSubmit}>
    <DatePicker name="checkIn" value={checkIn} onChange={setCheckIn} minDate={new Date()} required />
    <DatePicker name="checkOut" value={checkOut} onChange={setCheckOut} minDate={checkIn ?? new Date()} required />
    <Button type="submit" label="Book" />
</form>
