Resource Timeline

A day-based scheduler with one row per resource. Plan work by moving and resizing bars, reassign it by dropping it on another row, and show a load row under each resource.

Basic Usage

Pass resources, events and the date range. Overlapping events are placed in separate lanes.

Read-only timeline

Overlapping bars of a row are placed in separate lanes.

  resources={resources}
  events={events}
  startDate={start}
  endDate={end}
  isNonWorkingDay={(date, resourceId) => date.getDay() === 0 || date.getDay() === 6 || isLeave(date, resourceId)}

Features

Rows and Lanes

One row per resource. Bars that overlap in time are stacked in lanes so none is hidden.

Move, Resize, Reassign

Drag bars along time, resize either end, or drop them on another row to change the resource.

External Drop

Accepts items dragged from outside, such as an unscheduled list, onto a row and day.

Day Cells

Optional row of day cells under each resource, for load, availability or totals.

Keyboard Operable

Arrow keys move bars, Alt and Ctrl with arrows resize them, up and down arrows change the row.
