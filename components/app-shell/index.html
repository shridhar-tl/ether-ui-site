App Shell

A responsive application frame with header, collapsible and resizable sidebar, mobile drawer, aside panel and footer. Includes a skip link, focus management, persisted state and a hook to control the shell from any component.

Basic Usage

Application Shell

Header, collapsible sidebar and main content. Resize the window: below the breakpoint the sidebar becomes a drawer.

useAppShell

Any component rendered inside the shell can read its state and open, close or collapse the sidebar.

import { useAppShell } from 'fluxo-ui';

const MenuButton = () => {
    const { toggleSidebar, collapsed, isMobile, mobileOpen } = useAppShell();
    return <Button label={isMobile ? 'Menu' : collapsed ? 'Expand' : 'Collapse'} onClick={toggleSidebar} />;
};
